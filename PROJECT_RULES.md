# Project Rules

1. **No copyrighted characters or artwork in the repo** (no Kuromi, Sanrio or other licensed art,
   names or logos). GitHub Pages is public. Custom pictures are only chosen by the parent on the device.
2. Audience is ages 4-6: big buttons, 3 choices, voice for every question, no fail state and no timers,
   and every round ends with stars.
3. Every question must have exactly 3 distinct choices that include the correct answer (enforced by tests).
4. Progress lives only in the browser's localStorage. No accounts, no tracking, no ads, no network calls.
5. Merges to `main` and releases need the owner's explicit approval.
